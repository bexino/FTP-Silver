# FTP-Silver

A lightweight tool to easily start an FTP server.

## Quick Start

Release

### Configuration

After the server starts successfully for the first time, a script file named `start.bat` will be automatically created in the same directory where you run the software.

- Double-click `start.bat` to start the server using your previously saved settings.

## Build

Run `build.bat` to build the project from source.

### Output

No external dependencies are required.

The build output is located at:

`dist\FTPServer.exe`

# FTP 服务器

一个可轻松启动 FTP 服务器的轻量级工具。

## 快速开始

Release

### 配置说明

服务器首次成功启动后，会在运行程序的同一目录下自动创建一个名为 `start.bat` 的脚本文件。

- 双击 `start.bat`，即可使用此前保存的设置启动服务器。

## 构建

运行 `build.bat` 即可从源码构建项目。

### 构建产物

无需任何外部依赖。

构建产物位于：
